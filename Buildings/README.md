# Buildings

36 building miniatures for board games, divided into three sets of 12 models.

| Set | Theme |
|---|---|
| [Tech, AI & Digital](Tech_AI_Digital/) | AI research, chips, digital infrastructure and cybersecurity |
| [Automotive & Smart Manufacturing](Automotive_Smart_Manufacturing/) | Vehicles, batteries, industrial robotics and logistics |
| [Global Health & Care](Global_Health_Care/) | Hospitals, medical research, pharmaceuticals and care facilities |

Each set includes STL files, OpenSCAD sources, Bambu Studio 3MF projects, images and recorded print checks. Its README lists dimensions, print profiles for 0.4 mm and 0.2 mm nozzles, and the matching printed examples.
